# Portfolio DIALLO Moussa

Site statique (HTML / CSS / JavaScript), sans installation.

- Pages : index, projets, competences, certificats, formations, contact (.html)
- `css/style.css` styles · `js/main.js` animations, filtres, formulaire
- `img/` photo et visuels · `docs/` CV

Lancer : VS Code > extension Live Server > clic droit sur index.html > Open with Live Server.
